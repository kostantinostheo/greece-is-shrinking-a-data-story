# VizGenius

Interactive data visualizations about Greece's declining birth rate and ageing population.

Built with React, Vite, Tailwind CSS and Google Charts.

## Scripts

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server at http://localhost:5173/vizginius/ |
| `npm run build` | Production build into `build/` |
| `npm run preview` | Serve the production build locally |
| `npm run deploy` | Build and publish `build/` to GitHub Pages |

The site is served from `/vizginius/` (see `base` in `vite.config.mjs`).
